# ELL Reading

Guided Reading comprehension quizzes for Edwin and Sophia.

1. Pick a level, then the book you read.
2. Answer the questions.
3. Pick your name and tap **Send to teacher**. The score goes to the teacher's Google Sheet.

## Adding a level
Upload `data/level-g.json` (or `level-i.json`) in the same format as `data/level-f.json`.
The Level G / Level I button turns on by itself.
